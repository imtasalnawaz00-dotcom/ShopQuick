# shop_quick

Project context:
- App name: ShopQuick
- Type: Coursework prototype (CW1)
- Purpose: AI-assisted grocery savings app that helps users compare supermarket prices within their area and stay within budget.
- Users can enter their shopping list and budget.
- The app recommends the cheapest store combinations.
- Supports ranked store comparisons and split-basket suggestions.
- Includes receipt upload for future price validation.
- Built with Flutter using GetX state management and MVC architecture.
